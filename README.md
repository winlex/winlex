## 🧑‍💻 About

I design and operate backend and frontend parts of a product end-to-end and own the reliability of a portfolio of production services. I enjoy making complex accumulated systems safer and faster rather than rewriting them, and I use AI (Cursor, LLM, MCP) across the whole workflow.

A few things I've shipped and owned recently:

- 🛡 **Reliability** — introduced a circuit breaker, custom spans and distributed tracing to isolate local failures and improve end-to-end diagnostics.
- ⚙️ **Business rules engine** — real-time validation, automatic exclusion of invalid configurations and alerting for a large volume of business-rule configurations.
- ⚡ **Performance** — cut HTTP request time from ~15–20s down to ~4s (Doctrine relations, PostgreSQL indexes, algorithm fixes) using Symfony Profiler.
- 🔀 **State machine** — designed a lifecycle state model for a business-process orchestrator: lifecycle-linked states, overlap analysis and context actions.
- 📈 **Business impact** — retention automation that reduced operator load and improved a key retention metric.
- 🧪 **A/B testing gateway** — an integration layer that enabled multiple product teams to run overlapping experiments.
- 📅 **Forecasting automation** — replaced manual spreadsheet calculations for a large number of task types and conditions.
- 🧩 **Fullstack form generator** — schema-driven form generator with composite, integration and dynamic fields; reduced similar frontend work.
